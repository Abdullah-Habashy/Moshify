# توزيع النوافذ (WindowLayout)

برنامج ديسكتوب لويندوز: **رتّب نوافذك مرة واحدة، احفظ الشكل، ورجّعه بضغطة واحدة**.
بيحفظ كل نافذة (البرنامج، المكان، المقاس، الشاشة، مكبّرة/مصغّرة) — ووقت الاسترجاع
بيرجّع اللي مفتوح لمكانه، ويفتح اللي مقفول ويحطه في مكانه.

---

## التشغيل — الطريقة السهلة (بدون تسطيب)

نزّل **`WindowLayout.exe`** من صفحة
[Releases](../../releases) ودوس عليه دبل كليك. خلاص.

- مش محتاج بايثون ولا أي مكتبة.
- ملف واحد، تقدر تحطه في أي مكان أو تعمله Pin على شريط المهام.
- أول مرة ويندوز ممكن يقول *"Windows protected your PC"* لأن الملف مش موقّع
  رقميًا — دوس **More info** ← **Run anyway**.

مع الإصدار كمان **`winlayout-cli.exe`** — اختياري، نفس البرنامج بالظبط بس
لسطر الأوامر. نزّله لو هتستخدم الأوامر أو محتاج تشوف رسايل الأخطاء، لأن نسخة
النافذة بترجّع التحكم للـ CMD فورًا من غير كود خروج (طبيعة أي برنامج نافذة
على ويندوز).

## التشغيل من الكود المصدري

محتاج بايثون 3.9 أو أحدث من [python.org](https://www.python.org/downloads/windows/)
(علّم **Add python.exe to PATH**). بعدين دبل كليك على **`WindowLayout.pyw`**،
أو **`WindowLayout.cmd`** لو الـ `.pyw` مش مربوط ببايثون.

**مافيش أي مكتبة محتاجة `pip install`.** البرنامج بيكلّم ويندوز مباشرة عن طريق
`ctypes` اللي جوه بايثون نفسه.

### الواجهة

بتفتح في **نافذة ديسكتوب عادية** — من غير تبويبات ولا شريط عناوين. تحت الغطا
دي نافذة Chromium بوضع `--app` (Edge الموجود أصلاً على كل ويندوز 10/11)، لأن:

- Tk مش بيوصّل الحروف العربية صح على ويندوز، فالأسماء بتطلع مقطّعة.
- محرّك المتصفح بيعرض العربي RTL مظبوط، وبيسمح برسم خريطة التوزيع.

لو مالقاش أي متصفح Chromium، بيفتح في المتصفح الافتراضي بدل ما يفشل. في كل
الحالات السيرفر شغال على `127.0.0.1` بس وبيرفض أي طلب من غير التوكن اللي
بيتولّد مع كل تشغيل.

### الاستخدام في تلات خطوات

1. **رتّب** نوافذك على الشاشة زي ما إنت عايزها بالظبط.
2. دوس **«احفظ التوزيع الحالي»** ← اكتب اسم ← شيل علامة الصح عن أي نافذة
   مش عايزها في التوزيع (زي نافذة الواتساب أو الفولدر اللي فتحته بالصدفة) ← **احفظ**.
3. في أي وقت بعدين، دوس **«▶ استرجع»**.

### الضغطة الواحدة من غير ما تفتح البرنامج

من كارت التوزيع دوس **«اختصار على الديسكتوب»**. هيتعمل ملف `.lnk` على سطح المكتب
باسم التوزيع. دبل كليك عليه = استرجاع فوري. وتقدر تعمله Pin على شريط المهام،
وساعتها ويندوز بيديله اختصار `Win + رقم`.

## سطر الأوامر

نفس الملف بيشتغل من سطر الأوامر لو مرّرتله أوامر:

```cmd
winlayout-cli.exe list              :: أو winlayout.cmd لو شغال من الكود المصدري
winlayout list                      :: التوزيعات المحفوظة
winlayout save "شغل الصبح"           :: احفظ الوضع الحالي
winlayout save "شغل" --only chrome code   :: احفظ نوافذ برامج معيّنة بس
winlayout restore "شغل الصبح"        :: رجّع التوزيع
winlayout restore "شغل" --no-launch  :: ظبّط المفتوح بس، متفتحش حاجة
winlayout show "شغل الصبح"           :: تفاصيل التوزيع
winlayout delete "شغل الصبح"
winlayout shortcut "شغل الصبح"       :: اختصار على الديسكتوب
winlayout ui                         :: افتح الواجهة
```

## الاسترجاع بيشتغل إزاي

1. **بيدوّر على النوافذ المفتوحة ويطابقها** بالمحفوظ: أول حاجة اسم البرنامج
   (`chrome.exe`) وكلاس النافذة، وبعدين العنوان كمرجّح. العنوان لوحده مش كفاية —
   بيتغيّر مع كل ملف أو رسالة جديدة، فعدّاد زي `(3) WhatsApp` أو علامة التعديل `●`
   بيتشالوا قبل المقارنة.
2. **اللي مالقاهوش بيفتحه**: بالمسار الكامل للبرنامج، أو بالـ AppUserModelId لو
   برنامج من المتجر (UWP)، وبعدين بيستنى النافذة تظهر (٢٠ ثانية بحد أقصى) ويحطها
   في مكانها.
3. **بيحط كل نافذة** بالإحداثيات المحفوظة، ويرجّع حالتها (مكبّرة/مصغّرة/عادية)
   وخاصية «فوق الكل» لو كانت مفعّلة، ويرتّب النوافذ فوق بعضها بنفس الترتيب المحفوظ،
   وأخيرًا بيرجّع الفوكس للنافذة اللي كانت شغالة وقت الحفظ.

### لو الشاشات اتغيّرت

- **نفس الشاشات** ← الإحداثيات بترجع زي ما هي بالظبط.
- **شاشة اتغيّر مقاسها** ← الأبعاد بتتحوّل بالنسبة والتناسب على المقاس الجديد.
- **شاشة اتفصلت** ← نوافذها بتتنقل للشاشة الأساسية جوّه المساحة المتاحة،
  وبيظهرلك تنبيه في تقرير الاسترجاع.

في كل الحالات مفيش نافذة بتتساب بره حدود الشاشة.

## حاجات مهمة تعرفها

| الحالة | اللي بيحصل |
|---|---|
| برنامج شغال **كمسؤول (Admin)** | ويندوز بيمنع أي برنامج عادي إنه يحرّك نوافذه. التقرير بيقولك النافذة دي فشلت — شغّل `WindowLayout` كمسؤول لو محتاج تظبّطها. |
| **سطح مكتب افتراضي تاني** | ويندوز بيخفي نوافذ الأسطح التانية، فمش بتتحفظ. احفظ كل سطح مكتب في توزيع لوحده. |
| **تبويبات المتصفح** | البرنامج بيحفظ النافذة مش التبويبات. المتصفح نفسه هو اللي بيرجّع تبويباتك. |
| **برامج بتفتح نسخة واحدة** | لو البرنامج مقفول بيتفتح عادي. لو مفتوح وعايز نافذة تانية منه، بعض البرامج بترفض وبتوّرك النافذة الموجودة — التقرير بيقولك «مش لاقيينها». |
| **DPI مختلف بين الشاشات** | متظبّط: البرنامج بيسجّل نفسه Per-Monitor DPI Aware، فالإحداثيات بتبقى بكسل حقيقي على كل شاشة. |

## الملفات

التوزيعات بتتحفظ في:

```
%APPDATA%\WindowLayout\layouts\<اسم-التوزيع>.json
```

ولو حصلت مشكلة، فيه سجل بيتكتب في:

```
%APPDATA%\WindowLayout\log.txt
```

نسخة الـ exe نافذة من غير كونسول، يعني ملهاش مكان تطبع فيه — فالسجل ده هو
الطريقة الوحيدة تعرف إيه اللي حصل. ابعته لو البرنامج مافتحش.

ملف JSON عادي تقدر تفتحه وتعدّله بإيدك (الإحداثيات `[left, top, right, bottom]`).

> **ملاحظة خصوصية:** الملف بيتخزن فيه سطر تشغيل البرنامج عشان يقدر يفتحه تاني،
> ودا ممكن يحتوي على مسار ملف أو لينك كنت فاتحه. الملفات دي في `%APPDATA%`
> على جهازك — متحطهاش في مستودع عام.

## للمطوّر

```bash
python -m unittest discover -s tests                     # الاختبارات
WINLAYOUT_FAKE=1 python WindowLayout.py list             # سطح مكتب وهمي
WINLAYOUT_HOME=/path/to/dir python WindowLayout.py list  # مجلد تخزين بديل
build\build-exe.cmd                                      # بناء الـ exe محليًا
```

اختبارات `tests/test_win_smoke.py` هي الوحيدة اللي بتشغّل طبقة `ctypes` على
ويندوز حقيقي (بتعدّ الشاشات، وبتعمل نافذة Tk وتحرّكها وتكبّرها وتصغّرها وتتأكد
إنها راحت مكانها). بتتخطّى نفسها على أي نظام تاني، وبتتنفّذ في
`.github/workflows/build-windows.yml` مع كل push — ونفس الـ workflow ده هو اللي
بيبني الـ exe وينشره في Releases.

`WINLAYOUT_FAKE=1` بيبدّل طبقة ويندوز بسطح مكتب في الذاكرة، فتقدر تشغّل الواجهة
والاختبارات على لينكس أو ماك من غير ويندوز.

### بنية الكود

```
winlayout/
  model.py            الداتا: Rect / WindowInfo / MonitorInfo / Layout
  geometry.py         حساب الشاشات: مطابقة، قص، وإعادة توزيع لما الشاشات تتغيّر
  matching.py         مطابقة المحفوظ بالمفتوح (ترشيح بالنقط + توزيع واحد لواحد)
  engine.py           الالتقاط والاسترجاع فوق أي backend
  store.py            القراءة والكتابة في %APPDATA%
  shortcuts.py        اختصارات الديسكتوب (.lnk عن طريق WScript.Shell)
  arabic.py           صيغة العدد مع المعدود (نافذة / نافذتين / نوافذ)
  app.py              نقطة الدخول: نافذة لو من غير أوامر، CLI لو معاه أوامر
  cli.py              سطر الأوامر
  backend/
    win_backend.py    ويندوز عن طريق ctypes (user32 / kernel32 / dwmapi / shcore)
    fake_backend.py   سطح مكتب وهمي للاختبارات
  ui/
    server.py         السيرفر المحلي (توكن لكل تشغيل، مهام في الخلفية)
    desktop.py        فتح الواجهة كنافذة ديسكتوب
    index.html/app.js/style.css/icon.ico
build/
  WindowLayout.spec   وصفة PyInstaller
  make_icon.py        توليد الأيقونة من كود (من غير أي مكتبة صور)
  build-exe.cmd       بناء محلي
```

الملفات اللي مالهاش علاقة بويندوز (`model` / `geometry` / `matching` / `store`)
مفيهاش أي `ctypes`، عشان تتجرّب على أي نظام.
