# نظام التوجيه التلقائي بين الموديلات (Claude Code)

حل رسمي بالكامل: **Subagents** بموديل ومستوى تفكير محددين + سياسة توجيه تُحقن عند بدء كل جلسة + Hook صغير (Node، بلا اعتماديات) للتسجيل والحماية. لا يستخدم إضافات خارجية.

## المكونات
| الملف | الدور |
|---|---|
| `kit/agents/scout.md` | Haiku / low — بحث عن ملفات، مسارات، حالة |
| `kit/agents/worker.md` | Sonnet / medium — تحليل، مراجعة محدودة، ميتاداتا فيديو/صوت، تقارير، مكونات بسيطة، اختبارات |
| `kit/agents/render-check.md` | Sonnet / medium — Remotion stills ورندر قصير وفحوصات (لا يعدّل) |
| `kit/agents/deep-reviewer.md` | Opus / high — هندسة، Debugging صعب، قرارات تصميم (لا يعدّل) |
| `kit/agents/art-director.md` | Opus / high — رسم، تحريك، Storyboard، تكوين، صوت، هوية بصرية (لا يعدّل) |
| `kit/routing/policy.md` | سياسة التوجيه التي يقرأها المشرف عند بدء الجلسة (عدّلها بحرية) |
| `kit/hooks/router.mjs` | Hook + أداة تحكم: حقن السياسة، منع Fable، منع التفويض المتداخل، تسجيل الموديل الفعلي |
| `kit/skills/routing/SKILL.md` | أمر `/routing` داخل Claude Code |
| `install.mjs` | تثبيت / إلغاء تثبيت / استرجاع، مع نسخة احتياطية تلقائية |

## التثبيت على ويندوز (مرة واحدة)
يتطلب Node 18+ (موجود عندك لأن Remotion يحتاجه).

```powershell
cd <مسار هذا المجلد>\model-routing
node install.mjs --user --dry-run     # يعرض ما سيحدث فقط
node install.mjs --user               # تثبيت لكل المشاريع في %USERPROFILE%\.claude
# أو لمشروع واحد فقط:
node install.mjs --project "D:\Studio Cut"
```
بعدها افتح **جلسة جديدة** في تبويب Code في Claude Desktop أو في الطرفية، واكتب `/routing`.

## التحكم
| المطلوب | الأمر |
|---|---|
| هل النظام يعمل؟ ما الموديلات المستخدمة فعليًا؟ أخطاء؟ | `/routing` أو `node "$HOME\.claude\hooks\router.mjs" status` |
| آخر الأحداث الخام | `/routing log` |
| إيقاف مؤقت (من الجلسة التالية) | `/routing off` |
| إعادة التشغيل | `/routing on` |
| السماح بـ Fable عند طلبك الصريح فقط | `/routing fable on` (وإرجاعه `fable off`) |
| تعطيل لجلسة واحدة فقط | تشغيل Claude مع متغير البيئة `CLAUDE_ROUTING=off` |
| تعديل السياسة أو موديل أي مساعد | حرّر `~/.claude/routing/policy.md` أو `~/.claude/agents/<name>.md` (`model:` / `effort:`) |

قراءة لوحة الحالة: سطر «طلب» يعرض الموديل والتفكير المطلوبين ومصدرهما (`agent-file` أو `call`)، وسطر «نفّذ» يعرض الموديل الذي نفّذ فعلًا (`resolvedModel`) والتوكنز والمدة. «اختلاف المطلوب عن الفعلي» يجب أن يكون 0.

## الإيقاف الكامل والاسترجاع
```powershell
node install.mjs --user --uninstall          # يحذف الـhooks وملفات الحزمة ويعيد أي ملف كان لك بنفس الاسم
node install.mjs --user --restore <backup-id> # يعيد settings.json حرفيًا كما كان قبل التثبيت
```
النسخ الاحتياطية في `~/.claude/routing-backups/<id>/`، ورقم النسخة يظهر في نهاية التثبيت.

## حدود يجب معرفتها
- **لا يمكن لأي Hook أو إضافة تغيير موديل الجلسة الرئيسية أثناءها.** التوجيه التلقائي الحقيقي داخل الجلسة يتم عبر Subagents. لتغيير موديل المشرف نفسه استخدم `/model` و`/effort`.
- السياسة تُحقن عند **بدء** الجلسة، لذلك `on/off` يسري على الجلسات الجديدة. منع Fable يسري فورًا.
- قرار «أنفّذ بنفسي أم أفوّض» يتخذه الموديل حسب السياسة، وليس قاعدة حتمية. القواعد الحتمية هي فقط: موديل وتفكير كل مساعد، ومنع Fable، ومنع التفويض المتداخل.
- عند تشغيل المساعد في الخلفية، يُسجَّل الموديل الفعلي عند الإطلاق، لكن التوكنز لا تظهر في السجل.
- `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` أو `CLAUDE_CODE_EFFORT_LEVEL` إن ضُبطا يلغيان اختيارات المساعدين (المثبّت يحذّر منهما).

## التوصية بناءً على القياس
اجعل المشرف **Sonnet** في العمل اليومي (`/model sonnet`)، وسيصعّد تلقائيًا للمساعدين `art-director` و`deep-reviewer` على Opus عند الحاجة. انتقل بالمشرف إلى Opus (`/model opus`) في الجلسات الطويلة للتصميم والقرارات الفنية.
